# Аудиоинструменты АСШ Студии

Набор скриптов для работы со звуком без DAW: анализ трека, сниппеты под соцсети,
стемы, мастеринг, MIDI. Всё бесплатное и с открытым кодом, работает в облачной
среде Claude, на GitHub Actions или на любом Linux / WSL.

## Установка

```bash
cd audio
bash setup.sh --midi      # без --midi — без инструмента «аудио → MIDI»
.venv/bin/python selftest.py --full   # проверка, что всё работает
```

Нужны `ffmpeg` и `uv`. Первая установка занимает 3–5 минут, потом модели стемов
(~80 МБ) скачиваются при первом запуске `stems.py`.

## Инструменты

| Скрипт | Что делает |
|---|---|
| `analyze.py` | Темп, тональность, такты, акценты, громкость, лучшие отрезки 15/30/60 с |
| `snippet.py` | Нарезка под Shorts / Reels / VK Клипы: точная длина, старт с такта, фейды, −14 LUFS |
| `stems.py` | Разделение на вокал, барабаны, бас, остальное (Demucs) |
| `master.py` | Мастеринг по треку-образцу (Matchering) или простой цепочкой |
| `audio2midi.py` | Снимает ноты с аудио в MIDI для Ableton (Basic Pitch) |
| `midi_gen.py` | MIDI-заготовка по аккордам: барабаны, бас, аккорды, арпеджио |

Все скрипты понимают `--help`.

### Анализ трека

```bash
.venv/bin/python analyze.py трек.mp3
```

Печатает сводку и сохраняет `трек.analysis.json`: доли (`beats`), начала тактов
(`bars`), сильные акценты (`accents`) и энергию по секундам. Это сетка для монтажа:
склейки видео ставятся на такты и акценты, и картинка попадает в ритм.

Темп определяется в диапазоне 75–165 BPM. Для медленных баллад и быстрого DnB
задай его вручную: `--bpm 70`.

### Сниппеты для соцсетей

```bash
.venv/bin/python snippet.py трек.mp3                          # 15, 30 и 60 с, отрезок сам
.venv/bin/python snippet.py трек.mp3 --durations 30 --start 47   # с 47-й секунды (подгонится к такту)
```

Результат — папка `трек_snippets/` с файлами и `snippets.json`, где для каждого
сниппета записаны доли и акценты уже относительно его начала.

Автовыбор ищет самое громкое и самое повторяющееся место, обычно припев.
Громкость — −14 LUFS, пики не выше −1 dBTP: так YouTube, Instagram и VK не будут
приглушать трек и не появятся искажения после их сжатия.

### Стемы

```bash
.venv/bin/python stems.py трек.mp3                 # 4 стема
.venv/bin/python stems.py трек.mp3 --vocals        # вокал + минус
```

На процессоре трек 3 минуты разделяется примерно за 3–6 минут.

### Мастеринг

```bash
.venv/bin/python master.py мой_трек.wav --reference образец.mp3   # «звучи как этот трек»
.venv/bin/python master.py мой_трек.wav --lufs -14                # для соцсетей и стримингов
```

### MIDI

```bash
# заготовка трека по аккордам
.venv/bin/python midi_gen.py --chords "Am F C G" --bpm 124 --style house --bars 16 --out идея.mid

# снять мелодию вокала: сначала стем, потом ноты
.venv/bin/python stems.py трек.mp3 --vocals
.venv-midi/bin/python audio2midi.py трек_stems/трек_вокал.wav --preset vocal --bpm 124
```

Стили генератора: `house`, `pop`, `trap`, `lofi`, `rock`, `ambient`.
Барабаны записаны по стандарту General MIDI и сразу ложатся на Drum Rack в Ableton
(бочка — C1, снейр — D1, клэп — D#1, хэты — F#1 и A#1).

## Важно

Репозиторий **публичный**. Звук, видео и MIDI сюда не коммитятся (см. `.gitignore`):
треки клиентов должны оставаться приватными. Готовые файлы храним в Google Drive.
